# Machine Learning Portfolio 🚀

A curated collection of classical Machine Learning algorithms implemented in Python using Jupyter Notebooks. This repository demonstrates end-to-end workflows including exploratory data analysis (EDA), data preprocessing, feature scaling, model training, and performance evaluation across popular benchmark datasets.

---

## 📂 Repository Structure & Project Overview

| Notebook | Algorithm | Dataset | Task Type | Key Libraries / Concepts |
| :--- | :--- | :--- | :--- | :--- |
| **`LinearRegression(Housing).ipynb`** | Linear Regression | Housing Dataset | Regression | Feature correlation, MSE/RMSE, $R^2$ score, residual analysis |
| **`LogisticRegression(Pima).ipynb`** | Logistic Regression | Pima Indians Diabetes | Binary Classification | Sigmoid function, decision boundary, confusion matrix, ROC-AUC |
| **`DecisionTree(Pima).ipynb`** | Decision Tree Classifier | Pima Indians Diabetes | Binary Classification | Gini impurity/Entropy, tree pruning, feature importances |
| **`KNN(Heart).ipynb`** | K-Nearest Neighbors (KNN) | Heart Disease Dataset | Binary Classification | Distance metrics (Euclidean), feature standardization, finding optimal $k$ |
| **`NaiveBayes(Iris).ipynb`** | Gaussian Naïve Bayes | Iris Flower Dataset | Multi-class Classification | Bayes' theorem, conditional probability, multi-class metrics |

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Python 3.8+
- **Environment:** Jupyter Notebook / Google Colab
- **Core Libraries:**
  - `numpy` & `pandas` (Data manipulation and matrix operations)
  - `scikit-learn` (Model building, validation, and metrics)
  - `matplotlib` & `seaborn` (Data visualization and performance plotting)
